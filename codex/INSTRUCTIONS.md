# skill-shrinker for Codex

Paste the block below into your project's AGENTS.md (or Codex custom instructions),
and copy `SKILL.md` + `scripts/` from https://github.com/uniqaiapp/skill-shrinker into `.agents/skills/skill-shrinker/`.

---
When the user asks to shrink, shorten, compress, trim, dedupe or audit a CLAUDE.md, AGENTS.md, SKILL.md, cursor rule or system prompt, or asks how many tokens an instruction file costs, follow `.agents/skills/skill-shrinker/SKILL.md`. Run its scripts with `python3 .agents/skills/skill-shrinker/scripts/shrink.py`.
