# Contributing

Issues and pull requests are welcome. Keep changes small and include a before/after example in the PR description.

## Local checks

```bash
python3 tests/run.py          # all tests, stdlib only, under 10 seconds, no network
python3 scripts/shrink.py --help
```

Tests compare the committed outputs in `examples/` byte-for-byte with what the script prints. If you change the heuristics, regenerate them with the commands in `examples/README.md` and commit both the script and the outputs in the same PR.

## Rules

- Python 3.9+ standard library only. No `requirements.txt`, no packages, no network in tests.
- Any number that ends up in `README.md` must be produced by `scripts/shrink.py` on data in `examples/` (and say so), or carry a cited, dated source.
- Author and maintainer is UniqAI <support@uniqai.app>. Do not add personal names, handles or emails anywhere, including commit messages.
- Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`), subject under 72 characters.
- Keep `SKILL.md` under 500 lines. Long material goes to `references/`. Run the tool on its own skill before a release: `python3 scripts/shrink.py audit SKILL.md`.

## Adding a heuristic

1. Add the detection in `scripts/shrink.py` with a one-line comment on what it catches and what it misses.
2. Add a unit test in `tests/test_shrink.py` with a minimal document that triggers it and one that must not.
3. Regenerate `examples/*/audit.txt` and `examples/*/compare.md`, review the diff, update `references/playbook.md` if the rewrite rule changed.

## Assets

`assets/banner.svg`, `assets/banner-light.svg`, `assets/demo.svg` and `assets/social-preview.png` are generated by the org-wide design kit from `assets/demo.txt` (a real transcript of the commands in `examples/README.md`). They are not edited by hand; open an issue if one looks wrong.

## Deviations from org conventions

- `.gitignore` does not list a Node dependency folder: this repo has no Node code, and the forbidden-string test would flag the entry.
- The maintainer-only PNG script lives in the shared design kit, not in `scripts/`, so no file here needs an absolute path.
- `.github/workflows/ci.yml` drops the shared template's job-level `if: hashFiles(...)` guards and the Node job: `hashFiles` is evaluated before checkout at job level, so the guard would skip every job, and this repo has no Node code.
- `assets/demo.svg` plays once and holds the final frame (the org kit's default), instead of looping.
